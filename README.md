# Sourceblender community files

This repository holds Sourceblender's public organization profile and default
community files. GitHub displays these defaults for Sourceblender repositories
that do not provide their own file of the same type. A repository's own policy
takes precedence.

- [`profile/README.md`](profile/README.md) is the organization profile.
- `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, and `SUPPORT.md` are
  organization defaults.
- `.github/ISSUE_TEMPLATE/` and `.github/PULL_REQUEST_TEMPLATE.md` are
  default contribution templates.

These files contain no private operational configuration. A license for this
repository does not replace the license of any other repository: each project
must carry its own license when it is ready for public use and contribution.
