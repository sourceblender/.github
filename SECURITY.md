# Security Policy

Do not open a public issue for a suspected security vulnerability. Use the
affected repository's **Security** tab to submit a private vulnerability
report when that option is available. Otherwise, email
`ericmey@gmail.com` with the repository name, affected version or commit,
impact, and safe reproduction steps.

Do not send live tokens, secrets, transcripts, or captured memory. Redact
sensitive material and use synthetic examples. We will coordinate a fix and
disclosure with you. The affected repository's own `SECURITY.md` takes
precedence over this organization default, including its supported-version
policy and response targets.
