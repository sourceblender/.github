# Sourceblender

Sourceblender builds tools for memory, creative workflows, and local-first
software. Our public repositories include:

- [Musubi harness](https://github.com/sourceblender/musubi-harness) and its
  [Claude Code](https://github.com/sourceblender/musubi-claude),
  [Codex](https://github.com/sourceblender/musubi-codex),
  [Hermes](https://github.com/sourceblender/musubi-hermes), and
  [OpenClaw](https://github.com/sourceblender/musubi-openclaw) integrations.
- [ComfyUI Immich](https://github.com/sourceblender/comfyui-immich) and
  [ComfyUI Kotodama](https://github.com/sourceblender/comfyui-kotodama).

Start with a project's README for installation and support. Security reports
should follow that repository's `SECURITY.md`, or the
[organization default](https://github.com/sourceblender/.github/blob/main/SECURITY.md)
when it has no local policy.
