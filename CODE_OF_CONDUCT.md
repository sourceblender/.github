# Code of Conduct

Sourceblender projects welcome thoughtful participation. Be respectful of
other contributors and users. Disagreement about code and design is welcome;
harassment, threats, discriminatory abuse, doxxing, and unwanted sexual
attention are not.

Keep reports and reviews focused on the work. Do not publish someone else's
private information, credentials, conversations, or memory data. Maintainers
may edit or remove harmful content, close a thread, or restrict participation
to protect the community.

Report conduct concerns privately to `ericmey@gmail.com`. Include links or
context you are comfortable sharing. We will limit access to the report and
respond as promptly as we can. If a concern involves the listed contact, use
GitHub's [reporting tools](https://docs.github.com/en/site-policy/acceptable-use-policies/github-acceptable-use-policies)
instead.

A repository's own code of conduct takes precedence over this default.
